# Estúdio Fluxo

> **Estratégia, criatividade e tecnologia em um só fluxo.**

O **Estúdio Fluxo** é um site institucional desenvolvido com Python e Django, criado para apresentar a identidade, os serviços e os projetos do estúdio através de uma experiência web moderna, organizada e responsiva.

O projeto também serve como prática de desenvolvimento web com Django, explorando conceitos como **templates, views, URLs, arquivos estáticos, componentes reutilizáveis e organização de aplicações web**.

## Funcionalidades da Página

- Página inicial institucional
- Apresentação dos serviços e soluções
- Área de projetos/portfólio
- Interface responsiva para os usuários
- Templates reutilizáveis
- Sistematização das rotas com Django
- Organização de arquivos estáticos
- Estrutura preparada para futuras funcionalidades

## Tecnologias

- **Django**
- **Git & GitHub**
